# Full PIP

웹페이지의 동영상을 **브라우저 창 없이 동영상만 보이는 테두리 없는 창**으로 띄웁니다.
PIP(Picture-in-Picture)처럼 끌어서 옮기고 크기를 바꿀 수 있지만, Chrome PIP 와 달리 **크기 제한이 없어서**
32:9 모니터의 절반처럼 원하는 영역을 꽉 채워 볼 수 있습니다. 모든 동영상 사이트에서 동작합니다.

## 할 수 있는 것

- 단축키 한 번으로 페이지에서 가장 큰 동영상만 따로 띄우기 (iframe 안의 동영상 포함)
- 처음에는 모니터 면적의 25% 크기로, 원래 Chrome 창의 가운데에 열림 (동영상 비율 유지)
- 동영상을 끌어서 옮기기, 가장자리를 끌어서 크기 조절 — 크기 제한 없음
- Windows 스냅(화면 가장자리·모서리, 스냅 레이아웃)과 PowerToys FancyZones 로 영역에 맞춰 넣기
- 재생/일시정지·탐색은 동영상의 기본 컨트롤로 (사이트가 숨겨 둔 컨트롤도 다시 보이게 함)
- `Esc` 한 번으로 닫으면 탭이 원래 Chrome 창의 원래 자리로 돌아감

## 구성

| 폴더 | 역할 |
| --- | --- |
| `extension/` | Chrome 확장앱. 페이지에서 가장 큰 동영상을 찾아 화면에 꽉 채우고, 탭을 별도 팝업 창으로 옮깁니다. |
| `host/` | Windows 도우미 프로그램(C#). 테두리 없는 영상 창을 만들고 팝업 창을 그 안에 넣어 웹 화면 부분만 보이게 합니다. 영상 창의 이동·크기 조절·스냅도 처리합니다. |

### 왜 도우미 프로그램이 필요한가

- Chrome 의 PIP 창은 화면의 일정 비율보다 크게 만들 수 없습니다.
- 탭바·주소창·창 테두리는 Chrome 이 직접 그리기 때문에 확장앱으로는 없앨 수 없습니다.
- 창을 원하는 위치에 놓고, Windows 스냅·FancyZones 와 맞물리게 하려면 Windows 창을 직접 다뤄야 합니다.

그래서 확장앱이 탭을 팝업 창으로 옮기면, 도우미가 그 팝업 창을 자기 테두리 없는 창 안에 넣고
주소창·테두리가 창 밖으로 밀려나 잘리도록 위치를 맞춥니다. 둘은 Chrome 네이티브 메시징으로 통신합니다.

## 설치

1. 도우미 프로그램을 빌드하고 Chrome 에 등록합니다. (관리자 권한 필요 없음, .NET Framework 4 는 Windows 에 기본 포함)

   ```bash
   powershell -ExecutionPolicy Bypass -File host\install.ps1
   ```

2. Chrome 에서 `chrome://extensions` 를 열고 **개발자 모드**를 켠 뒤 **압축해제된 확장 프로그램 로드**로 `extension` 폴더를 선택합니다.
   확장앱 ID 가 `jeblbgpopdkdlglillcdelanpgbhfhdi` 인지 확인합니다. (도우미가 이 ID 의 확장앱만 허용합니다)

## 사용법

1. 동영상이 있는 페이지를 엽니다.
2. `Alt+Shift+F` (또는 확장앱 아이콘 클릭) → 동영상만 담긴 영상 창이 열립니다.
3. 끄기: `Esc`, `Alt+Shift+F` 다시 누르기, 또는 `Alt+F4` → 탭이 원래 창으로 돌아갑니다.

### 영상 창 다루기

| 하고 싶은 것 | 방법 |
| --- | --- |
| 옮기기 | 동영상 위를 끕니다. (아래쪽 재생바 영역은 제외 — 재생 위치를 그대로 조절할 수 있습니다) |
| 크기 조절 | 창 가장자리의 얇은 테두리나 모서리를 끕니다. |
| 화면 절반·4분의 1에 맞추기 | 화면 가장자리·모서리로 끕니다. 위쪽으로 끌면 Windows 스냅 레이아웃이 나타납니다. |
| FancyZones 영역에 맞추기 | 끄는 동안 `Shift` 를 누르고 원하는 영역에 놓습니다. |
| 맨 앞으로 가져오기 | 영상 창을 클릭합니다. (그냥 클릭은 평소처럼 동영상에도 전달됩니다) |
| 재생·탐색 | 동영상의 기본 컨트롤이나 사이트 단축키(스페이스, 방향키 등)를 씁니다. |

영상 창으로 보는 동안에는 사이트의 전체화면 기능(전체화면 버튼, `f` 키, 더블클릭)이 동작하지 않습니다.
이미 영상만 보여 주고 있고, 전체화면이 되면 영상 창이 모니터 전체로 끌려 나가기 때문입니다.

## 설정

`extension/worker.js` 맨 위의 값을 바꾸고 `chrome://extensions` 에서 확장앱을 새로고침합니다.

| 값 | 기본값 | 설명 |
| --- | --- | --- |
| `INITIAL_AREA` | `0.25` | 영상 창의 처음 크기 (모니터 면적 대비). `1` 이면 원래 Chrome 창 크기 그대로 엽니다. |
| `TOPMOST` | `false` | `true` 면 영상 창이 항상 다른 창 위에 뜹니다. |

단축키는 `chrome://extensions/shortcuts` 에서 바꿀 수 있습니다.

## 문제가 생기면

- 확장앱 아이콘에 `!` 가 뜨면 아이콘에 마우스를 올려 오류 내용을 확인하세요. 대부분 도우미 프로그램이 설치되지 않은 경우입니다.
- 도우미 프로그램의 예상하지 못한 오류는 `%TEMP%\AreaFullscreenHost.log` 에 기록됩니다.
- 도우미를 다시 빌드할 때는 영상 창을 모두 닫은 뒤 `install.ps1` 을 다시 실행합니다. (실행 중인 exe 는 덮어쓸 수 없습니다)

## 제거

```bash
powershell -ExecutionPolicy Bypass -File host\uninstall.ps1
```

그 다음 `chrome://extensions` 에서 확장앱을 삭제합니다.

## 참고

- Windows + Chrome 전용입니다. (도우미 등록 위치가 `HKCU\Software\Google\Chrome\NativeMessagingHosts`)
- 닫힌(closed) shadow DOM 안에 있는 동영상은 찾지 못합니다.
- 내부 식별자(`com.areafullscreen.host`, `AreaFullscreenHost.exe` 등)는 예전 이름을 그대로 씁니다.
